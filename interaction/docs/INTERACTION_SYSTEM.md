# 交互系统说明

## 分类

| 分类 | 文件 | 功能 |
| --- | --- | --- |
| 界面工程 | `../ui/final/ture1.HMI` | 最终 TJC 串口屏项目 |
| 串口接收 | `../rtl/tjc_hmi_rx.v` | 解析音色、音量、增益、音符、按键掩码和重同步命令 |
| 串口发送 | `../rtl/tjc_hmi_uart_tx.v` | 更新页面、音符、电平、音量、增益、触控状态和波形 |
| 输入归并 | `../rtl/touch_note_merge.v` | 合并 16 键矩阵与串口屏瞬时音符/和弦掩码 |
| 控制仲裁 | `../rtl/tjc_control_merge.v` | 合并 PC 与屏幕音量和增益事件 |
| 矩阵扫描 | `../rtl/matrix_keyscan16.v` | 4×4 行扫描和去抖 |
| 板载按键 | `../rtl/key_capture2.v` | 音色/八度按键同步与去抖 |
| 调试遥测 | `../rtl/keyboard_status_uart.v` | PC 状态、电平和波形查询/回传 |

## 串口参数

- 波特率：115200；
- 数据位：8；
- 停止位：1；
- 校验：无；
- 字节序和帧格式由 HMI 工程及 `tjc_hmi_rx.v` 共同定义。

## FPGA 接收命令

| 帧 | 命令 | 数据范围/说明 |
| --- | --- | --- |
| `A5 10 VV 5A` | 选择音色 | `VV = 0..3` |
| `A5 20 VV 00 00 00 00 5A` | 设置音量 | `VV=0` 为静音，其余映射到 1..256 |
| `A5 30 5A` | 请求重同步 | 显示状态重新发送 |
| `A5 40 VV 5A` | 波形显示增益 | 允许 1、4、16、32、64 |
| `A5 50 NN 5A` | 瞬时音符 | `NN = 0..15` |
| `A5 51 LL HH 5A` | 16 键掩码 | `HH` 高字节、`LL` 低字节 |

任何非 `5A` 结束、非法停止位或超时的半帧都会被丢弃。屏幕音符有效后由 `touch_note_merge` 合并，并在计时超时后清除，避免屏幕掉线造成持续按键。

## FPGA 回传内容

`tjc_hmi_uart_tx` 以限速 TJC 文本命令更新：

- 当前页面和音色；
- 矩阵/屏幕音符十六进制掩码；
- 左右声道电平条；
- 主音量数值与滑块；
- 波形显示增益；
- 触控在线状态；
- 32 点实时波形帧。

波形帧只在可以完整发送时启动，避免半帧覆盖；页面重同步会清除旧状态并重绘。

- 正式界面：`ui/final/ture1.HMI`
- 历史版本：`ui/archive/tune_screen_keys.HMI`
